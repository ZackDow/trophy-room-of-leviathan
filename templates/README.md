# Templates

Copy the template, rename it, fill in every `{…}`.

| Template | For | Goes in |
| -------- | --- | ------- |
| [course.md](course.md) | A course | `courses/<provider>/<course>/README.md` |
| [challenge-writeup.md](challenge-writeup.md) | A picoCTF challenge | `security/picoctf/<event>/<challenge>.md` |
| [wargame-progress.md](wargame-progress.md) | An OverTheWire game | `security/overthewire/<game>.md` |
| [leetcode-problem.md](leetcode-problem.md) | A LeetCode problem | `leetcode/<NNNN>-<slug>/README.md` |
| [note-summary.md](note-summary.md) | A handwritten note, written up | `notes/<topic>/<note>.md` |
| [trophy-project.md](trophy-project.md) | A flagship project | `trophies/<project>.md` |
| [timeline-month.md](timeline-month.md) | A month | `timeline/YYYY-MM.md` |
