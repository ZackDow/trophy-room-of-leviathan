## Layout

```
notes/
└── <topic>/
    ├── <note>.md       ← from templates/note-summary.md
    └── img/            ← optional, one compressed image per note at most
```

Example: `notes/linear-algebra/eigenvalues.md`.

Folders appear when their first note is added.
